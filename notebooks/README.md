# 노트북 규칙

- 파일명: `NN_주제_작성자.ipynb` (예: `01_eda_rainfall_hong.ipynb`)
- 검증된 로직은 `src/data_ai/`로 이동하고, 노트북에서는 `from data_ai import ...`로 사용한다.
- 커밋 전 출력 셀은 정리한다(대용량 출력 방지).

- `02_pipeline_end_to_end.ipynb`: 데이터 적재 → 결합 → 결측 전략 비교·학습 → 롤링 검증 → 최종 학습·제출 파일 → 그림까지 한 번에 실행하는 노트북. `scripts/train.py` 와 같은 함수를 쓰며 결과(제출 파일 124건)가 일치하는지 마지막에 확인한다. 실행 결과가 저장돼 있어 열어서 읽기만 해도 된다.
