# 방법 설명서 — 댐·하천 유해남조류 7일 예측

> 팀명: 19일의 월요일 · 팀원: [이름 기입] · 저장소: https://github.com/Nautika01/data.AI
> 작성 기준일 2026-10-26 (모델 확정). 모든 수치는 이 저장소 코드로 재현한 값이며, `make data && make train && make evaluate` 로 다시 얻을 수 있다.

## 1. 과제 이해

- 경보제 5개 지점(해평, 강정·고령, 칠서, 물금·매리, 회남)에서 기준일로부터 7일 뒤 유해남조류 세포수(cells/mL)를 예측하는 회귀 과제.
- 정답은 기준일+7일에 가장 가까운 측정(±3일). 채점 조합은 주최 측 `eval_pairs.csv`(학습 2,310 / 검증 256 / 평가 124)를 그대로 사용.
- 지표: log10(세포수+1) RMSE·MAE, 원 단위 R²·NSE. 참고지표 10,000 cells/mL 초과 F1.

## 2. 데이터와 결합

| 도메인 | 파일 | 사용 항목 | 결합 방식 |
|---|---|---|---|
| 수질·조류 | `algae_measure.csv` | 세포수(4속 합계·속별), 수온, pH, DO, 투명도, 탁도, 클로로필-a, 우점종 | 기준 테이블. 이전 1~3회 측정값(lag)과 측정 간격 추가 |
| 기상 | `asos_daily.csv` | 기온(평균·최고·최저), 강수, 풍속, 습도, 일조, 일사, 전운량, 지면온도 | `stations.csv`의 최근접 ASOS 지점. 기준일 포함 과거 7·14·28일 평균/합/최대/최소 |
| 수문 | `dam_daily.csv` | 유입량, 총방류량, 여수로 방류량, 취수량, 댐 강우, 저수위 | 지점별 상류 다목적댐 집합의 흐름 합산 + 대표 댐 저수위와 월별 평년 편차. 과거 7·14·28일 집계 |
| 하천(추가) | `wamis_daily.csv` (WAMIS, 팀 수집) | 낙동강 본류 보 수위(구미보하, 강정고령보하, 창녕함안보상, 삼랑진교) | 당일·7·28일 평균, 7일 변화량. 회남은 해당 없음. 유량은 2026년분만 제공되어 제외 |
| 상류 지점(번들 재활용) | `algae_measure.csv` | 같은 수계 다른 경보지점의 세포수 | 낙동강 본류 바로 상류 지점(해평→강정고령→창녕함안→물금매리)과 수계 내 다른 지점 평균의 기준일 이전 최근 log10 세포수(14일 이내). 회남(금강)은 해당 없음 |

- 지점↔댐 대응은 README에 없어 수계 지리로 정했다. 해평·강정·고령: 안동·임하·영주·성덕·군위·김천부항, 칠서: +합천·남강, 물금·매리: +밀양, 회남: 용담·대청. 조정지댐은 본댐과 중복되어 제외. 근거는 `configs/bloom.yaml` 주석.
- 체류시간 대리변수: 저수량이 없어 `방류 7일 평균 / 유입 7일 평균`, `방류 7일 평균 / 방류 28일 평균`, 대표 댐 저수위의 월별 평년 편차로 설계.
- 강수 결측(NaN)은 무강수로 보고 0 처리. 기상·댐 집계는 결측이 거의 없음(일사 7일 평균 16% 제외).
- **기준일 이후 정보 차단**: 모든 일 자료 집계는 기준일 포함 과거만 사용(`rolling` + `merge_asof backward`). 평년값·중앙값은 학습 구간에서만 계산. 입력 열은 허용 목록 방식으로 선택해 정답·분할·날짜 열이 섞이면 실행이 중단된다.

## 3. 결측 대체 전략 (평가 항목)

수질 항목 결측 13.7%, 세포수 5.4%. 세 전략을 같은 조건에서 비교했다.

| 전략 | 방법 | 검증 2025 rmse_log10 | R² |
|---|---|---|---|
| native | LightGBM 기본 결측 처리 | 0.714 | 0.146 |
| ffill_flag | 직전 측정값으로 채우고 결측 표시 열 추가, 못 채우면 지점·월 중앙값 | 0.704 | 0.173 |
| site_month_median | (지점, 월) 학습 구간 중앙값으로 채우고 결측 표시 열 추가 | 0.716 | 0.168 |

세 전략의 차이(0.70~0.72)는 유의하지 않다. 제출 모델은 검증 rmse_log10이 가장 낮은 전략을 자동 선택한다(현재 ffill_flag).

## 4. 모델

- LightGBM 회귀, 목표 log10(세포수+1), 손실 L2(공식 지표 rmse_log10과 일치).
- 하이퍼파라미터: learning_rate 0.03, num_leaves 15, min_child_samples 20, feature_fraction 0.8, bagging 0.8, λ2 1.0, extra_trees(분할점 무작위화), 시드 42. 반복 수는 공식 검증에서 early stopping으로 결정(146).
- 5개 지점 통합 모델. 지점 ID와 우점종은 범주형 입력.
- 최종 제출 모델은 학습+검증(≤2025) 전체로 재학습(반복 수 ×1.1) 후 2026년 평가 조합을 예측. 예측값은 원 단위로 환산해 0 이상 정수로 반올림.

## 5. 검증 설계와 결과

| 구분 | 학습 | 검증 | n | rmse_log10 | mae_log10 | R² | NSE | F1@10,000 |
|---|---|---|---|---|---|---|---|---|
| 공식 분할 | ~2024 | 2025 | 256 | 0.704 | 0.53 | 0.173 | 0.173 | 0.651 |
| 롤링 | ~2021 | 2022 | 271 | 0.832 | – | 0.014 | 0.014 | 0.429 |
| 롤링 | ~2022 | 2023 | 248 | 0.763 | – | 0.027 | 0.027 | 0.375 |

베이스라인(검증 2025): persistence rmse_log10 0.883 / R² −0.282, climatology 0.907 / 0.028. 모델은 persistence 대비 log RMSE 20% 개선.
5~10월 기준일만 보면 검증 rmse_log10 0.57.

변형 실험(동역학 피처, 지점별 모델, 회남 2012~2015 제외, 5시드 평균, Huber·Poisson·Tweedie, 편향 보정, 가중치, 블렌드, 외부 수위·저수량 자료)은 대부분 기준 모델과 잡음 수준 차이였다(`docs/modeling_notes.md`, `reports/experiments*.csv`).
유일하게 채택한 변경은 4차 실험의 **상류 지점 세포수 입력 + extra_trees**로, 네 검증 구간(2022·2023·2024·2025) 평균 rmse_log10이 0.784→0.772(시드 3개 모두 개선, 시드 간 편차 0.006)였다.
외부 자료 4종(DataON 댐유역 하천 수위, 다목적댐 운영 저수량, WAMIS 본류 수위, 국립환경과학원 수질자동측정망)도 같은 틀로 검증했으나 모두 잡음 수준이었다. 수위는 파이프라인에 남겨 두었고(효과 없음, 해가 되지도 않음), 나머지는 미사용.

목표 성능 대비: 과제 목표는 원 단위 R² 0.6·NSE 0.5이나 검증 2025에서 0.17, 롤링 2024에서 0.37로 **미달**이다. 로그 RMSE는 persistence 대비 20% 개선, 경보 기준 F1은 0.65다. 미달 원인은 6·7절.

## 6. 해석

- 피처 중요도(gain, 최종 모델) 상위: log10 세포수, 기준일 세포수, 경보 단계, 직전 측정 세포수, Microcystis 세포수·비율, 지면온도 28일 평균, 수온, 기온 28일 평균. 상류 지점 세포수와 수계 평균은 132개 중 16·17위. 선행연구의 수온·수문 설명력과 방향이 같다.
- 원 단위 R²·NSE가 낮은 이유: 수십만 cells/mL 봉우리 몇 개가 지표를 좌우하며, 로그 공간 모델은 봉우리를 과소예측한다. 로그 지표와 원 단위 지표는 상충하며, 둘을 동시에 올리는 변형은 찾지 못했다.
- 예측 구간(q10~q90) 포함률은 검증 73%(명목 80%)로 다소 과신. 운영 활용 시 보수적으로 해석해야 한다.
- 수질자동측정망 검증에서 질산성질소와 7일 뒤 세포수의 상관이 −0.34로, 녹조가 늘 때 질산염이 소모되는 경향이 보였다. 다만 예측 개선으로는 이어지지 않았다(이미 입력에 있는 클로로필·세포수와 중복).

## 7. 한계와 향후 과제

- 7일 선행 예측에 필요한 정보(향후 기상, 하천 구간 수리 조건)가 입력에 없다. 과제 목표 R² 0.6·NSE 0.5는 현재 입력으로 달성하지 못했다.
- 2026 평가 구간은 5~10월만이며 심한 녹조 해로 학습 분포와 다르다(기준일 세포수 10,000 초과 비율 학습 10% vs 평가 58%).
- 회남 2012~2015년은 수온 전부 결측. DataON 하천 수위 자료는 2024년까지라 평가 구간에 쓸 수 없어 미사용. 수질자동측정망은 지점·항목이 고르지 않고(해평·구미 클로로필 없음) 기존 입력과 중복되어 미사용.
- 국립환경과학원 AI 녹조 정밀 예측정보와의 벤치마크 비교는 주최 측 종합 평가 항목이므로 이 문서에서는 수행하지 않았다.
- 롤링 검증 2022·2023에서는 대표 댐 수위 평년값이 2024년까지 자료로 계산되어 소폭의 사후 정보가 포함된다(공식 분할에는 해당 없음).

## 8. 재현

```bash
pip install -r requirements.txt && pip install -e .
make data        # data/raw 번들 → data/processed/bloom.parquet
make train       # 전략 비교·롤링 검증·최종 학습 → reports/submission.csv, reports/metrics.csv
make evaluate    # 지표 표
make score       # 제출 형식 검사(+번들 실측 자체 채점, 참고)
```

시드 고정(42). 예측값 하드코딩·실측 조회 없음. 입력은 기준일 포함 과거 자료만 사용.
