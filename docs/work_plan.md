# 작업 계획 — 댐·하천 유해남조류(녹조) 7일 예측

> 확정 과제: **문제해결 부문 과제 7 "댐·하천 유해남조류(녹조) 7일 예측 AI 모델 개발"**
> 작성일: 2026-10-19 · 접수 마감: **2026-11-06** · 발표평가: **2026-11-25**

## 1. 목표

- 경보제 지점 5곳에서 **기준일 + 7일 유해남조류 세포수(`iem_bgalage_cell_co`)를 회귀 예측**한다. 공식 정의는 [task_spec.md](task_spec.md).
- 목표 성능: 검증('25) 기준 **R² 0.6, NSE 0.5 이상**. 보조지표로 10,000 cells/mL 초과 여부 F1.
- 수질 + 기상 + 댐 운영(수문) **3개 도메인 융합**과 **결측 대체 전략**을 명시적으로 설계·평가한다.
- 산출물: 재현 코드, 평가 예측 파일(`sample_submission.csv` 형식), 방법 설명서.

## 2. 문제 정의 (공식 규칙 반영)

| 항목 | 정의 |
|---|---|
| 단위 | (지점코드, 기준일) 한 행. 기준일은 실제 측정일 |
| 입력 | 기준일 이전 수질(세포수, 클로로필-a, 수온, pH, 투명도, 탁도, DO), 기상 과거 7·14·28일 집계, 댐 운영 과거 7·14·28일 집계, 체류시간 대리변수 |
| 정답 | 기준일+7일에 가장 가까운 측정(±3일)의 세포수. 없거나 결측이면 제외 (`target_valid`) |
| 학습 목표 | log10(세포수+1) 회귀. 제출은 원 단위 cells/mL |
| 베이스라인 | persistence(기준일 값), climatology(지점·월 중앙값), blend |
| 검증 | **공식 분할**: ~2024 학습 / 2025 검증 / 2026 평가. 추가로 2022·2023을 검증 연도로 한 롤링 검증 |
| 지표 | rmse_log10, mae_log10, R², NSE, F1@10,000 (`bloom_metrics`) |

금지: 무작위 분할, 기준일 이후 관측값 사용, 예측값 하드코딩·룩업.

## 6. 차별화 포인트 (반드시 포함)

1. **엄밀한 검증**: 공식 분할 + 롤링 검증, persistence/climatology 베이스라인 대비 개선폭 명시.
2. **운영 지표**: 보조지표 F1@10,000(경계 기준)과 급증 사례(5일 만에 10배) 성능을 따로 제시. 제거설비 선제 배치 리드타임 관점으로 해석.
2-1. **결측 대체 전략 비교**: 앞값 채우기 / 지점·월 중앙값 / 결측 플래그 + 모델 내 처리의 성능 차이를 표로 제시(공식 평가 항목).
3. **3개 분야 융합**: 수질 + 기상 + 댐 운영. 방류량·체류시간이 예측에 기여하는지 SHAP으로 보여 "댐 운영으로 녹조 완화"라는 정책 함의 제시.
4. **해석 가능성**: 지점별 피처 기여도, 실제 발령 사례 복기 그림.
5. (여유 시) **예측 구간**: quantile 회귀로 상·하한 제시.
