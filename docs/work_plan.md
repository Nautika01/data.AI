# 작업 계획 — 댐·하천 유해남조류(녹조) 7일 예측

> 잠정 과제(팀 논의 후 확정 예정): **문제해결 부문 과제 7 "댐·하천 유해남조류(녹조) 7일 예측 AI 모델 개발"**
> 작성일: 2026-10-19 · 접수 마감: **2026-11-06** · 발표평가: **2026-11-25**

## 1. 목표

- 조류경보제 지점별로 **7일 뒤 남조류 세포수**와 **경보 단계(관심·경계·대발생)** 를 예측하는 모델을 만든다.
- 단순 정확도가 아니라 **"경보 단계 전환을 며칠 앞서 잡아내는가"** 를 핵심 지표로 삼아, 제안 기관(수자원공사)이 취수·방류 운영에 바로 쓸 수 있는 형태로 제시한다.
- 수질 + 기상 + 댐 운영(수문) **세 분야 데이터를 융합**해 가점 요건을 충족한다.

## 2. 문제 정의

| 항목 | 정의 |
|---|---|
| 단위 | (지점, 측정일) 한 행 |
| 입력 | 당일 및 과거 수질(남조류 세포수, 클로로필-a, 수온, 총인, 총질소, pH, DO), 기상(기온, 일사, 강수, 풍속), 댐 운영(저수위, 유입량, 방류량, 체류시간) |
| 목표 1 (분류) | 7일 뒤 경보 단계. 조류경보제 기준: 관심 1,000 cells/mL, 경계 10,000, 대발생 1,000,000 (2회 연속 초과 시 발령) |
| 목표 2 (회귀) | 7일 뒤 남조류 세포수. log1p 변환 후 학습 |
| 베이스라인 | 지난 측정값 유지(persistence), 같은 주차 다년 평균(climatology) |
| 검증 | 연도별 롤링 검증. 예: 2019~2023 학습 → 2024 평가, 2019~2024 학습 → 2025 평가 |
| 지표 | 분류: 단계별 F1, 단계 상승 전환 재현율·정밀도, 선행 적중률. 회귀: log 스케일 MAE·RMSE |

주의: 무작위 분할 금지. 미래 정보 누수를 막기 위해 모든 피처는 예측 시점 이전 데이터만 사용한다.

## 3. 데이터

자세한 다운로드 방법은 [data_sources.md](data_sources.md) 참조.

| 분야 | 데이터 | 출처 | 주기 | 역할 |
|---|---|---|---|---|
| 수질 | 조류경보제 남조류 세포수, 클로로필-a, 수온 | 물환경정보시스템(water.nier.go.kr) | 주 1회 | 정답 + 핵심 피처 |
| 수질 | 호소 수질측정망(TP, TN, pH, DO, BOD) | 물환경정보시스템 | 월 1회 | 보조 피처 |
| 기상 | ASOS 일 자료(기온, 일사, 일조, 강수, 풍속) | 기상자료개방포털(data.kma.go.kr) | 일 | 융합 축 1 |
| 수문 | 댐 저수위·유입량·방류량 | WAMIS / 공공데이터포털(수자원공사) | 일 | 융합 축 2 |
| 보조 | 지점 좌표, 댐 제원(총저수량 등) | 물환경정보시스템, 수자원공사 | 고정 | 체류시간 계산, 지점 특성 |

대상 지점(초안, 데이터 확인 후 확정): 대청호(문의·회남·추동), 보령호, 주암호, 영천호, 안동호·임하호, 낙동강 칠서·물금 등 조류경보제 운영 지점 중 결측이 적은 6~10곳.

## 6. 차별화 포인트 (반드시 포함)

1. **엄밀한 검증**: 연도별 롤링 검증 + persistence/climatology 베이스라인 대비 개선폭 명시.
2. **운영 지표**: 경보 단계 상승 전환의 선행 탐지율과 오경보율을 함께 제시. 오경보·미탐지 비용을 표로 정리.
3. **3개 분야 융합**: 수질 + 기상 + 댐 운영. 방류량·체류시간이 예측에 기여하는지 SHAP으로 보여 "댐 운영으로 녹조 완화"라는 정책 함의 제시.
4. **해석 가능성**: 지점별 피처 기여도, 실제 발령 사례 복기 그림.
5. (여유 시) **예측 구간**: quantile 회귀로 상·하한 제시.
