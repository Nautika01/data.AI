# 데이터 수집 가이드 — 녹조 7일 예측

모든 원본은 `data/raw/`(대회 제공) 또는 `data/external/`(공개 데이터)에 저장하고,
`data/README.md`의 표에 출처·수집일·기간을 기록한다. 파일명은 `출처_내용_기간.csv` 형식.
(예: `nier_algae_alert_2015_2025.csv`, `kma_asos_daily_2015_2025.csv`)

## 1. 조류경보제 남조류 세포수 (정답 데이터)

- 사이트: 물환경정보시스템 <https://water.nier.go.kr>
- 메뉴: 수질정보 → 조류경보제 (또는 "조류 측정 자료")
- 내려받을 항목: 지점, 측정일, 남조류 세포수(cells/mL), 클로로필-a, 수온, 경보 단계
- 기간: 가능한 전체(2015년 이후 권장)
- 비고: 지점별·연도별로 나뉘어 있으면 전부 받아 하나로 합친다. 지점명 표기가 연도마다 다를 수 있으니 통일표를 만든다.

## 2. 호소 수질측정망 (보조 피처)

- 사이트: 물환경정보시스템 → 수질측정망 자료 → 호소
- 항목: 총인(TP), 총질소(TN), pH, DO, BOD, COD, SS, 투명도
- 주기: 월 1회. 주 단위 자료와 합칠 때는 해당 월 값을 그대로 붙이거나 선형 보간한다.
- 공공데이터포털 API로도 제공됨: <https://www.data.go.kr> 에서 "수질측정망" 검색

## 3. 기상 (융합 축 1)

- 사이트: 기상자료개방포털 <https://data.kma.go.kr>
- 메뉴: 데이터 → 기상관측 → 지상 → 종관기상관측(ASOS) → 일 자료
- 항목: 평균·최고·최저기온, 일강수량, 평균풍속, 일조시간, 일사량, 평균상대습도
- 지점: 각 조류경보제 지점에 가장 가까운 ASOS 지점(예: 대청호 → 청주 131, 보령호 → 보령 235, 주암호 → 순천 174, 안동호 → 안동 136, 물금 → 양산 288 등). 거리 매핑표를 `data/external/station_map.csv`로 만든다.
- 회원가입 후 CSV 다운로드. API 키가 필요하면 `.env`의 `KMA_API_KEY`에 저장.

## 4. 댐 운영 (융합 축 2)

- 사이트: 국가수자원관리종합정보시스템 WAMIS <http://www.wamis.go.kr> → 댐 → 댐 운영 현황(일)
- 대안: 공공데이터포털에서 "한국수자원공사 댐 운영" 검색 (수위, 저수량, 유입량, 총방류량 일 자료)
- 항목: 저수위, 저수량, 유입량, 총방류량, 강우량
- 파생: 체류시간(일) ≈ 저수량 / 방류량. 유입량 7일 누적, 방류량 7일 평균.
- 하천 지점(칠서, 물금 등)은 상류 댐(남강댐, 밀양댐, 안동·임하댐 등) 방류량과 하천 유량관측소 자료를 쓴다.

## 5. 지점 메타데이터

- 조류경보제 지점 좌표: 물환경정보시스템 지점 정보
- 댐 제원(총저수량, 유역면적, 준공연도): 수자원공사 <https://www.water.or.kr> 또는 WAMIS 댐 제원
- `data/external/sites.csv`에 지점명, 위도, 경도, 댐명, ASOS 지점번호, 지점 유형(댐/하천)을 기록

## 6. 결합 규칙

1. 기준 테이블: 조류경보제 (지점, 측정일).
2. 기상·댐 운영은 일 자료이므로 측정일 기준 과거 7일·14일·28일 집계를 먼저 만든 뒤 결합한다(미래 값 사용 금지).
3. 월 단위 수질은 측정일이 속한 달의 값을 붙인다.
4. 결합 후 결측 비율을 지점별로 표로 내고, 결측 30% 이상 지점은 제외한다.

## 7. 저작권·이용 조건

- 물환경정보시스템, 기상자료개방포털, WAMIS, 공공데이터포털 자료는 공공누리 조건으로 이용 가능하다. 출처 표기를 보고서에 남긴다.
- 대회 제공 데이터는 대회 규정의 이용 범위를 따른다.
