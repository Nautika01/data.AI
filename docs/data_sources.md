## 1. 결합 방법 (`configs/bloom.yaml`, `src/data_ai/bloom.py`)

| 단계 | 내용 |
|---|---|
| 조류경보제 | `algae_measure.csv` 열 이름을 표준 이름으로 매핑(수온 `iem_wtrtp`→`water_temp` 등). 세포수·수온·클로로필의 이전 1~3회 측정값(lag)과 측정 간격 추가 |
| 기상 | `stations.csv`의 `asos_stn_id`로 지점↔ASOS 연결. 강수 결측(NaN)은 0으로. 기준일 포함 과거 7·14·28일 집계(`w_` 접두) |
| 댐 | 지점별 **상류 다목적댐 목록**(설정 `station_dams`)의 유입·방류·여수로·취수·강우를 합산, 대표 댐(`primary_dam`) 저수위와 월별 평년 편차(`d_level_anom`, 평년은 ≤2024만 사용). 체류시간 대리변수 `d_flow_ratio7d`, `d_outflow_rel28d` |
| 정답 | `eval_pairs.csv`의 (지점, 기준일, 정답측정일, split)을 그대로 사용. test 정답은 비움 |

지점별 상류 댐(README에 매핑이 없어 수계 지리로 검증, 근거는 `configs/bloom.yaml` 주석):

| 지점 | 상류 댐(합산) | 대표 댐(수위) |
|---|---|---|
| HP 해평 | 안동, 임하, 영주, 성덕, 군위, 김천부항 | 안동 |
| GJGR 강정·고령 | 해평과 동일 (금호강 댐은 강정·고령보 하류 합류라 제외) | 안동 |
| CS 칠서 | + 합천, 남강 | 합천 |
| MGMR 물금·매리 | + 밀양 | 남강 |
| DCHN 회남 | 용담, 대청 | 대청 |

조정지댐(안동·임하·합천·대청조정지)은 본댐 방류와 중복되어 제외했다. 매핑 변경은 설정 파일만 고치면 된다.

## 2. 데이터에서 확인한 사실 (EDA 노트북 기준)

- 측정 수: HP 566, GJGR 600, CS 624, MGMR 366('20-05 시작), DCHN 783('12-04 시작). 중앙 측정 간격 7일, 정답 간격 정확히 7일인 비율 80.4%
- 결측: 수질 항목 13.7%, 세포수 5.4%, 독소 90%+. 수온은 2012~2015년(회남) 전부 결측
- 기상·댐 집계는 결측 0% (일사 7일 평균만 16%)
- 분포 차이: 기준일 세포수 10,000 초과 비율 train 9.9% / valid 19.1% / **test 58.1%** (test는 5~10월만, 심한 녹조 해)
- 세포수 0인 측정이 학습 구간의 약 1/4 (겨울철)
- 베이스라인(검증 '25): persistence log10 RMSE 0.88, 원 단위 R² −0.28 / climatology R² 0.03 / blend R² 0.17 → **원 단위 R²·NSE는 큰 값 몇 개가 좌우**하므로 대량 발생 시점을 맞히는 것이 핵심
