# 공식 과제 정의 — 댐·하천 유해남조류(녹조) 7일 예측

> 출처: 대회 과제 안내문 (2026-10-15 업데이트: 배포 데이터와 일치·명확화를 위한 문제·데이터 설명 수정, 데이터 파일 변경 없음).
> 이 문서가 `work_plan.md`보다 우선한다. 안내문이 다시 바뀌면 여기부터 고친다.

## 배경

- **심화·조기화**: 폭염 장기화·강우 패턴 변화로 상수원 녹조 확대 및 시기 조기화.
  물금·매리 경보 발령일수 '22년 196일, '23년 146일, '24년 160일, '25년 194일(부산시).
  강정·고령 '26년 첫 경보 5. 18. 발령, 최근 3년(6월 말~7월 초) 대비 약 2개월 조기화.
  '26년 8월 3주 기준 경보제 4개소 경계, 3개소 관심. 강정·고령 8. 13. 49,400 → 8. 18. 483,021 cells/mL (5일 만에 약 10배).
- **먹는물 안전**: 마이크로시스틴(MC-LR)은 IARC Group 2B. 물금취수장 하루 84만 톤, 부산 공급량의 약 33%.
  정부 '26년 녹조계절관리제 시행, 주요 지점 채수 당일 결과 발표. '26. 4.~8. 녹조 보도 169건.
- **융합 필요**: 수질(기후에너지환경부)·수문(K-water)·기상(기상청) 3개 도메인 결합 시 예측력 제고 기대.
  선행연구 상관(세포수 로그 기준): 수온 0.630, 월 0.374, 댐 유입량 0.188, 총방류량 0.187. 오염원 위치 변수는 0.1 내외.
  (송찬영 외, 「머신러닝을 활용한 낙동강 유해남조류 발생 예측」, 한국지능시스템학회 논문지 33(1), 2023, pp.29-36)
- **현업 연계**: K-water가 경보제 29개소 53지점 중 16개소 26지점 조사·분석. 녹조제거설비 22대, 물환경설비 431대, 조류차단막 59개소.
  제거설비는 '경계' 발령 시 가동 원칙 → **7일 선행 예측으로 설비 선제 배치 리드타임 확보**.
- **목적**: 공개 데이터 기반 재현 가능한 융합형 AI 예측. 조류경보 대응, 취수원 운영(고도정수, 취수 심도, 댐·보 방류 연계) 의사결정 지원.

## 과제 정의

| 항목 | 내용 |
|---|---|
| 문제 | 경보제 지점별 **기준일로부터 향후 7일 유해남조류 세포수(cells/mL) 예측 — 회귀 단일 과제, 배점 100%** |
| 기준일 `base_date` | 실제 측정이 존재하는 날짜로 한정 |
| 정답 | `base_date + 7일`에 가장 가까운 측정일의 값. **차이 ±3일 이내만 채점**. 범위 안에 측정이 없거나 정답 결측이면 그 (지점, 기준일)은 제외 |
| 예측 대상 열 | `iem_bgalage_cell_co` (유해남조류 세포수 합계, cells/mL) |
| `target_date` | 기준일+7일에 가장 가까운 실제 정답 측정일. **`sample_submission.csv`에 지정된 날짜 사용** |

### 입력 데이터 (수질·수문·기상 3개 도메인 공개 데이터)

| 도메인 | 데이터 | 항목 |
|---|---|---|
| 수질·조류 | 조류경보제 측정자료 | 수온, pH, 투명도, 탁도, DO, 세포수, 클로로필-a, 조류독소 등 |
| 수문 | 다목적댐 운영자료 | 강우량, 유입·방류량, 저수위, 저수량, 저수율 |
| 기상 | 인근 ASOS 종관관측 | 기온, 강수량, 풍속, 습도, 일조·일사 등 |
| 수문(보강) | DataON 「댐유역 하천 일평균수위」 국가참조표준(K-water) | **번들 미포함**, 필요 시 직접 내려받아 활용 |

- **융합 난제**: 주기가 다른 이종 시계열(비정기·주간 수질 ↔ 일 단위 수문·기상) 결합이 핵심.
  누적 강우, 체류시간 대리변수(저수량/방류량), 이동평균 수온 등 융합 특징 설계 요구.
- **현실 제약**: 유량 증가 시 미채수 등 결측 존재 → **결측 대체 전략도 평가에 포함**.
- **산출물**: 학습 모델(재현 코드), 평가 대상 예측 결과 파일, 방법 설명서.

## 목표 성능

- 회귀 **R² 0.6, NSE 0.5 이상**.
- 선행연구 R² 0.880은 당일 변수로 당일 세포수를 추정(무작위 8:2 분할)한 값. 7일 선행 예측은 난도가 높아 상한 참고치.

## 평가

| 항목 | 내용 |
|---|---|
| 분할 | 학습 ~'24년 / 검증 '25년 / 평가 `sample_submission.csv`에 지정된 2026년 조합. **미래 정보 사용 금지** |
| 회귀 지표 | log10(세포수+1) 변환 RMSE·MAE, 원 단위 R²·NSE 병행. NSE = 1 − Σ(관측−예측)² / Σ(관측−관측평균)² |
| 종합 | 회귀 100% 순위화, 상위작 코드 재현성 검증. 국립환경과학원 AI '녹조 정밀 예측정보'('26. 5. 4.~, 향후 7일, 13개소) 벤치마크 비교 |
| 보조지표 | 실제·예측 세포수의 **10,000 cells/mL 이상 여부 F1** (기준 초과 상황 예측 성능 확인) |

### 유의사항 (실격 사유)

- 예측값 하드코딩, 실측치 룩업테이블 포함 금지.
- **기준일 이후 시점의 관측값을 입력으로 사용 금지.**
- 재현 실행 결과가 제출 파일과 유의하게 다르면 실격.
