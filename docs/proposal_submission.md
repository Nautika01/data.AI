## 제안내용

### 1. 데이터 활용 방안 및 분석 방법론

- **과제 이해**
  - 경보제 5개 지점(해평, 강정·고령, 칠서, 물금·매리, 대청호 회남)에서 기준일로부터 7일 뒤 유해남조류 세포수(cells/mL)를 예측하는 회귀 과제
  - 정답은 기준일+7일에 가장 가까운 측정값(±3일 이내)이며, 학습 ~2024년 / 검증 2025년 / 평가 2026년(sample_submission.csv 지정 조합)으로 분할
  - 평가는 log10(세포수+1) RMSE·MAE와 원 단위 R²·NSE, 보조지표로 10,000 cells/mL 초과 여부 F1
- **활용 데이터** (대회 배포 자료 및 데이터 사전 기준)
  - 수질·조류: 조류경보제 측정자료 — 수온, pH, 투명도, 탁도, DO, 세포수, 클로로필-a 등. 세포수는 Microcystis·Anabaena·Oscillatoria·Aphanizomenon 4속 합계
  - 수문: 다목적댐 운영자료(WAMIS 기반 일자료 dam_daily.csv, API 수집 보조자료 dam_operation_api.csv) — 강우량, 유입·방류량, 저수위, 저수량, 저수율
  - 기상: 인근 ASOS 종관관측 — 기온, 강수량, 풍속, 습도, 일조·일사
  - 보강 검토: DataON 「댐유역 하천 일평균수위」(K-water, 2024년 데이터까지 수록). 번들 미포함이므로 활용 가능 범위를 확인한 뒤 결정
- **데이터 융합 방법** — 주기가 다른 이종 시계열(비정기·주간 수질 ↔ 일 단위 수문·기상)을 결합
  - 기준일을 기준으로 일 단위 수문·기상 자료를 과거 일정 기간(예: 7·14·28일) 창으로 집계해 수질 측정 행에 결합
  - 과제 설명에서 요구한 융합 특징을 구현: 누적 강우, 체류시간 대리변수(저수량/방류량), 이동평균 수온
  - 수질 항목의 이전 측정값과 측정 간격, 계절(월) 정보를 추가
  - 기준일 이후 시점의 관측값은 입력에 사용하지 않도록 결합 단계에서 차단
- **결측 대응** — 과제 설명에 명시된 결측(유량 증가 시 미채수 등)에 대해 복수의 대체 전략(직전값 유지+결측 표시, 지점·월 통계값 대체, 모델 자체 처리)을 동일 조건에서 비교하고 결과를 보고서에 포함
- **모델링** — 목표 변수 log10(세포수+1) 회귀
  - 단순 기준 예측(기준일 값 유지, 지점·월 평균)으로 하한선을 설정한 뒤 그래디언트 부스팅 계열 모델(LightGBM) 적용
  - 변수 기여도 분석으로 수온·수문·기상 변수의 역할 해석
- **검증** — 공식 분할을 준수하고, 추가로 과거 연도를 검증 연도로 바꿔 가며 반복 검증해 안정성 확인. 공식 지표와 보조지표를 모두 산출하고, 국립환경과학원 AI '녹조 정밀 예측정보'(물모아플랫폼)와 비교
- **재현성** — 데이터 결합·학습·예측 파이프라인을 코드로 작성해 저장소로 제출하고 난수 시드를 고정. 예측값 하드코딩·실측치 룩업 미사용
