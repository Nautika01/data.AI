## 제안내용

### 1. 데이터 활용 방안 및 분석 방법론

- **활용 데이터 (3개 도메인 공개 데이터)**
  - 수질: 조류경보제 측정자료(국립환경과학원) — 대상 5개 지점(해평, 강정·고령, 칠서, 물금·매리, 대청호 회남)의 유해남조류 세포수, 수온, pH, 투명도, 탁도, DO, 클로로필-a
  - 수문: 다목적댐 운영자료(K-water, WAMIS 일자료) — 강우량, 유입량, 총방류량, 저수위, 저수량, 저수율. API 보조자료는 결측 보완에 활용
  - 기상: 지점 인근 ASOS 종관기상관측(기상청) — 기온, 강수량, 풍속, 습도, 일조·일사
  - 보강(여유 시): DataON 「댐유역 하천 일평균수위」 국가참조표준 — 댐~취수지점 구간 수리 조건 보강(2024년까지 수록이므로 학습 구간 분석에 한정)
- **이종 주기 융합 설계** — 비정기·주간 수질 자료를 기준으로, 일 단위 수문·기상 자료를 기준일 포함 과거 7·14·28일 창으로 집계해 결합
  - 누적 강우(7·14·28일), 이동평균 기온·일사·일조, 유입·방류량 평균 및 누적
  - 체류시간 대리변수 = 저수량 / 총방류량, 저수율 변화량
  - 수온·세포수의 이전 측정값(lag 1~3회)과 측정 간격, 월·연중일(계절성)
  - 기준일 이후 시점의 관측값은 어떤 피처에도 사용하지 않도록 결합 단계에서 차단
- **결측 대응 전략(평가 항목 대응)** — 유량 증가 시 미채수 등 결측을 전제로 세 가지 전략을 동일 조건에서 비교해 채택
  - ① 결측 플래그 + 직전값 유지, ② 지점·월 중앙값 대체, ③ 트리 모델의 결측 자체 처리
- **모델링** — 목표 변수 log10(세포수+1) 회귀
  - 베이스라인: persistence(기준일 값 유지), climatology(지점·월 중앙값)로 하한선 설정
  - 본 모델: LightGBM(5개 지점 통합 학습 + 지점 특성 피처). 필요 시 지점별 모델과 비교
  - 보조: quantile 회귀로 예측 구간 제시, SHAP으로 수온·체류시간·누적 강우 기여도 해석
- **검증 및 평가** — 공식 분할(~2024 학습 / 2025 검증 / 2026 평가) 준수, 추가로 2022·2023년을 검증 연도로 한 롤링 검증으로 안정성 확인
  - 지표: log10 RMSE·MAE, 원 단위 R²·NSE(목표 R² 0.6, NSE 0.5), 보조지표 10,000 cells/mL 초과 여부 F1
  - 급증 사례(수일 내 10배 증가)에 대한 선행 탐지 성능을 별도 점검하고, 국립환경과학원 AI 녹조 정밀 예측정보와 동일 기간 비교
- **재현성** — GitHub 저장소에 데이터 결합·학습·예측 파이프라인을 공개하고 난수 시드 고정. 한 번의 명령으로 데이터 결합부터 제출 파일 생성까지 재현. 예측값 하드코딩·실측 조회 미사용
