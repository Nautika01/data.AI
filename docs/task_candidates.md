## 선정 기준

1. **데이터 확보 가능성** — 대회 제공 데이터 외에 융합할 공개 데이터가 있는가 (가점 요건).
2. **문제 정의의 명확성** — 평가 지표를 정량적으로 정의할 수 있는가.
3. **실용성** — 제안 기관이 바로 활용할 수 있는 형태(대시보드, 위험도 지도, 경보 기준 등)로 결과를 제시할 수 있는가.
4. **팀 역량** — 도메인 지식, 사용 가능한 기술 스택.
5. **일정** — 11-06 접수까지 남은 기간 내 완성 가능한 범위인가.
