# 데이터 관리

`data/` 아래 실제 데이터 파일은 git에 올리지 않는다(`.gitignore`). 아래 표에 출처와 메타데이터만 기록한다.

## 목록

| 파일/디렉터리 | 출처(URL) | 수집일 | 기간/범위 | 라이선스 | 비고 |
|---|---|---|---|---|---|
| `raw/` | | | | | 대회 제공 원본 |
| `external/` | | | | | 융합용 외부 데이터 |

## 디렉터리 규칙

- `raw/`: 원본 그대로 보관, 수정 금지.
- `external/`: 외부 공개 데이터(기상청, 공공데이터포털, KOSIS 등).
- `interim/`: 정제 중간 산출물.
- `processed/`: 모델 입력용 최종 데이터셋. `scripts/make_dataset.py`로 생성.
